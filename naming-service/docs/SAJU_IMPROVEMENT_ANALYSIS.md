## ❌ 부족한 기능 (다른 사이트 대비)

### 1. 십성(十星) 분석 ⚠️ **중요도: 매우 높음**

**현재:** 미구현
**전문 사이트:** 필수 기능

#### 십성이란?
일간(나)을 기준으로 다른 천간/지지와의 관계를 분석하는 명리학 핵심 요소

| 십성 | 의미 | 오행 관계 | 영향 |
|------|------|-----------|------|
| **비견(比肩)** | 형제, 동료 | 나와 같음 | 경쟁, 협력 |
| **겁재(劫財)** | 경쟁자 | 나와 같음 (음양 다름) | 재물 손실 위험 |
| **식신(食神)** | 표현, 창조 | 내가 생하는 것 | 재능, 복록 |
| **상관(傷官)** | 표현, 반항 | 내가 생하는 것 (음양 다름) | 독립성, 변화 |
| **편재(偏財)** | 유동 재산 | 내가 극하는 것 | 사업, 투자 |
| **정재(正財)** | 고정 재산 | 내가 극하는 것 (음양 다름) | 안정, 저축 |
| **편관(偏官)** | 권력, 압박 | 나를 극하는 것 | 도전, 극복 |
| **정관(正官)** | 명예, 직위 | 나를 극하는 것 (음양 다름) | 질서, 규율 |
| **편인(偏印)** | 지식, 직감 | 나를 생하는 것 | 학문, 예술 |
| **정인(正印)** | 학업, 어머니 | 나를 생하는 것 (음양 다름) | 학습, 보호 |

#### 작명에 미치는 영향
```
예시: 일간이 甲木(갑목)인 경우
- 편재가 많으면 → 金(금) 오행 한자 추가로 재물운 강화
- 정관이 없으면 → 辛(신금) 한자로 정관 보충
- 식신이 많으면 → 火(화) 오행 한자로 표현력 강화
```

**개선 필요:**
- [ ] 일간 기준 십성 계산 함수
- [ ] 십성 개수 분석 (어떤 십성이 많은지/없는지)
- [ ] 십성 부족 시 보완 한자 추천
- [ ] 십성 균형 점수 계산

### 2. 십이운성(十二運星) 분석 ⚠️ **중요도: 높음**

**현재:** 미구현
**전문 사이트:** 대부분 제공

#### 십이운성이란?
일간의 생명력/에너지 상태를 12단계로 분석

| 운성 | 의미 | 에너지 | 작명 영향 |
|------|------|--------|----------|
| **장생(長生)** | 탄생 | 10% | 새로운 시작, 성장 한자 |
| **목욕(沐浴)** | 정화 | 20% | 변화, 정화 한자 |
| **관대(冠帶)** | 성장 | 30% | 발전, 확장 한자 |
| **건록(建祿)** | 왕성 | 80% | 안정, 번영 한자 |
| **제왕(帝旺)** | 절정 | 100% | 강력, 리더십 한자 |
| **쇠(衰)** | 쇠퇴 | 70% | 차분, 내실 한자 |
| **병(病)** | 질병 | 40% | 치유, 회복 한자 필요 |
| **사(死)** | 죽음 | 20% | 재생, 전환 한자 필요 |
| **묘(墓)** | 무덤 | 10% | 보호, 안정 한자 필요 |
| **절(絕)** | 단절 | 5% | 돌파, 혁신 한자 필요 |
| **태(胎)** | 임신 | 15% | 잠재력, 씨앗 한자 |
| **양(養)** | 양육 | 25% | 성장, 교육 한자 |

**개선 필요:**
- [ ] 일간 기준 십이운성 계산
- [ ] 병/사/묘/절 운성일 때 보완 한자 추천
- [ ] 십이운성 기반 성격 분석

### 3. 대운(大運) 분석 ⚠️ **중요도: 높음**

**현재:** 미구현
**전문 사이트:** 필수 기능

#### 대운이란?
10년 주기로 변하는 운의 흐름

**현재 문제점:**
- 생년월일만 기준으로 작명
- 앞으로 10년, 20년 후 운세 고려 안 됨

**개선 필요:**
```typescript
// 예시: 2025년생 아이의 대운
{
  age: 0-10,   // 2025-2035: 乙亥 대운 (목/수) → 목/수 한자 좋음
  age: 10-20,  // 2035-2045: 甲戌 대운 (목/토) → 목/토 한자 좋음
  age: 20-30,  // 2045-2055: 癸酉 대운 (수/금) → 수/금 한자 좋음
}

// 작명 시 고려:
// - 0-10세에 좋은 이름 vs
// - 20-30세(사회생활)에 좋은 이름 vs
// - 전 생애 균형잡힌 이름
```

**개선 필요:**
- [ ] 대운 계산 함수 (순행/역행)
- [ ] 연령대별 대운 표시
- [ ] 대운 기준 작명 추천 (청소년기/청년기/중년기)
- [ ] 대운 변화 시점 알림

### 5. 격국(格局) 판단 ⚠️ **중요도: 높음**

**현재:** 미구현
**전문 사이트:** 전문 사이트는 필수

#### 격국이란?
사주의 전체적인 구조와 패턴

**주요 격국:**
- 정관격: 안정, 공직
- 편관격: 권력, 군인
- 식신격: 복록, 예술
- 정재격: 재물, 사업
- 종격(從格): 특수 격국

**작명 영향:**
```
예시: 정관격 사주
→ 명예롭고 단정한 한자 추천 (正, 直, 淸, 賢)

예시: 식신격 사주
→ 창의적이고 풍요로운 한자 추천 (藝, 豊, 創, 樂)
```

**개선 필요:**
- [ ] 격국 자동 판단 알고리즘
- [ ] 격국별 추천 한자 리스트
- [ ] 격국과 직업 적성 연결

### 6. 조후(調候) 용신 ⚠️ **중요도: 매우 높음**

**현재:** 단순 오행 부족만 고려
**전문 사이트:** 계절별 조후 용신 고려

#### 조후 용신이란?
**계절에 따라 필요한 오행이 다름**

| 계절 | 특성 | 조후 용신 | 작명 예시 |
|------|------|----------|----------|
| **봄(춘)** | 목왕 | 금(벌목), 토(뿌리) | 金, 玉, 土, 坤 |
| **여름(하)** | 화왕 | 수(시원함) | 水, 洋, 淸, 河 |
| **가을(추)** | 금왕 | 화(단련), 수(조화) | 火, 煥, 水, 潤 |
| **겨울(동)** | 수왕 | 화(온기), 목(생기) | 火, 煥, 木, 林 |
| **환절기(토월)** | 토왕 | 목(소통) | 木, 林, 森, 榮 |

**현재 문제:**
```typescript
// 현재 방식: 단순 오행 개수만 계산
오행 개수: 목2 화1 토3 금1 수1
→ 화가 1개니까 화 보충 (❌ 틀릴 수 있음)

// 개선 필요: 계절 고려
겨울생(수왕): 화가 1개라도 더 필요 (✅ 정확)
여름생(화왕): 화가 많으니 수로 중화 (✅ 정확)
```

**개선 필요:**
- [ ] 계절별 조후 용신 계산
- [ ] 월령(月令) 기준 사주 강약 판단
- [ ] 조후 용신 우선순위 표시

### 9. 육친(六親) 분석 ⚠️ **중요도: 낮음**

**현재:** 미구현
**전문 사이트:** 일부 제공

#### 육친이란?
사주로 보는 가족 관계

- 부모운: 정인/편인으로 판단
- 형제운: 비견/겁재로 판단
- 배우자운: 정재/편재(남), 정관/편관(여)로 판단
- 자녀운: 식신/상관으로 판단

**작명 활용:**
부모운이 약하면 → 부모를 돕는 효(孝) 관련 한자
형제운이 강하면 → 화목(和) 관련 한자

**개선 필요:**
- [ ] 육친 분석 함수
- [ ] 육친 기반 작명 가이드
